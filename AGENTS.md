# Development Rules

- Use available skills from ~/.Codex/skills/gstack/agents
- Never write duplicate code
- Run tests before asking to ship
- CRITICAL: A GeM contract (GEM_BID_COPY or PURCHASE_ORDER) is NOT a proof of work completion. A valid proof of work completion/execution must be one of:
  - An Invoice (INVOICE)
  - A Bank Certificate indicating payment
  - An Execution Certificate (EXECUTION_PROOF) indicating executed value
  - A previous IOCL work document
